How It Works

  • The floating card appears after the page fully loads — never on first paint.
  • Triggers fire once; whichever condition (scroll / time) is met first wins.
  • Clicking "Shop Now" on the card opens the full premium popup.
  • Session storage prevents re-showing after close or purchase click.
  • Changes saved here go to localStorage (this browser only). Copy JSON → file to persist.
