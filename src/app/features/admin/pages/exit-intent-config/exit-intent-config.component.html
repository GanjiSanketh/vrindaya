How it works

  • Desktop: triggers when cursor moves toward the top of the browser window.
  • Mobile: triggers after 30 seconds of inactivity or when switching apps.
  • Shown only once per session — won't interrupt the same visitor twice.
  • The View New Arrivals button navigates to /new-arrivals.
