How It Works

  • Settings are fetched once when the website loads and cached — clicks never trigger a database read.
  • When Website Tracking is off, nothing is recorded at all.
  • Each event is saved only when its own switch is on.
  • Admins and store staff browsing the site are never counted.
  • Changes apply to the live storefront immediately after saving.
