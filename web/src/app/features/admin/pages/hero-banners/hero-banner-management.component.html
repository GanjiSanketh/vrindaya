How It Works

  • Only one active hero banner exists — publishing always replaces it.
  • The storefront reads the banner straight from Firestore, so a publish goes live with no code changes.
  • While no banner is published, the website keeps showing the default banner from assets.
  • Only Admin and Super Admin accounts can update banners.
